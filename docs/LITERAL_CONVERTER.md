# JSON ↔ PHP Array ↔ Python 字典 / 列表

## 入口与操作

菜单“JSON ↔ PHP / Python”，沿用预留路由 #/php-array。

- 源格式和目标格式各可选择 JSON、PHP Array、Python 字典 / 列表，支持六个跨格式方向；选择相同格式可重新排版。
- 缩进支持 2 空格、4 空格、Tab。
- 示例按源格式生成；转换支持 Ctrl / ⌘ + Enter。
- 结果只读，可复制和下载 converted.json / converted.php / converted.py。
- “结果反向转换”将结果作为输入，交换源与目标后立即执行。
- 修改内容或选项会清除旧结果；清空删除输入和结果，保留设置。
- 使用现有 CodeMirror 编辑器；JSON 有语法高亮，PHP/Python 当前按纯文本展示。没有文件导入功能。

## 数据类型映射

| 数据 | JSON | PHP | Python |
| --- | --- | --- | --- |
| 映射 | {"key": value} | ["key" => value] | {"key": value} |
| 列表 | [value] | [value] | [value] |
| 真 / 假 | true / false | true / false | True / False |
| 空值 | null | null | None |
| 字符串 | 双引号 | 单/双引号输入，双引号输出 | 单/双引号输入，双引号输出 |
| 数字 | 十进制整数、小数、指数 | 相同受限语法 | 相同受限语法 |

顶层可以是上述任意类型，不限于映射。保留成员顺序；字符串会重新转义，不承诺原始引号风格不变。

数字记录为原始 token，不经过 JavaScript Number。例如 9223372036854775807、1.2300e+20 原样输出。**这仅保证转换文本不丢精度**：将结果交给真实 PHP/Python 执行时，大整数、浮点和指数仍受语言及平台范围影响。不执行计算，不支持 NaN、Infinity、十六进制、下划线数字、+1、.5 或 1. 等扩展写法。

## PHP 输入范围

- 支持短数组 [...]、长数组 array(...)（不区分 array 关键字大小写），嵌套和尾逗号。
- 可有一个末尾分号；不接受 PHP 标签、return、赋值、变量、函数、对象、注释或表达式。
- 布尔、null 不区分大小写。
- 键支持字符串和整数，不支持布尔、null、浮点键，即使真实 PHP 会自动转换它们。
- 按 64 位 PHP 8.3+ 模拟整数索引：隐式键从已使用的最大整数键加一；首次负索引后的自动键同样递增。整数键越界、隐式索引溢出拒绝。
- 合法范围内的规范十进制数字字符串键等价于整数键；"08"、"+1" 不归一化。超过 64 位范围的数字字符串键保留为字符串。
- 如果按出现顺序恰好为 0、1、2…，输出列表；否则输出字符串键映射。稀疏、负数和混合键不强制变成列表。
- 重复键或归一化后冲突直接报错，不模拟 PHP 后值覆盖前值，避免静默丢数据。

### 空数组与有损边界

PHP 数组不能区分 JSON 空对象 {} 与空列表 []。输出 PHP 时它们均为 []，页面始终提示此边界。

从 PHP 转出时，“PHP 空数组解释”默认列表，也可选择映射；该选项对输入中所有空数组生效，不能恢复丢失的逐节点类型。数字字符串键经过真实 PHP 或本工具再次解析后，也可能被转换为列表索引。因此跨 PHP 不承诺所有输入无损往返。

### 字符串转义

- PHP 单引号仅处理转义单引号和反斜杠，其他反斜杠保留。
- PHP 双引号支持换行、回车、Tab、垂直制表符、换页、ESC、引号、反斜杠、转义美元符、两位 ASCII 十六进制及 Unicode 花括号码点转义。
- 未转义美元符拒绝，避免把变量插值误当普通文本。输出会自动转义美元符。
- 非 ASCII 十六进制字节转义拒绝；请直接输入 UTF-8 文字。工具不处理任意 PHP 二进制字符串。
- 未支持转义报错，不猜测八进制或未知转义含义；字符串内原始换行须改为转义。
- PHP 输出拒绝孤立 Unicode 代理项。

## Python 输入范围

- 支持字典 {...}、列表 [...]、单/双引号、True、False、None 及尾逗号。
- 字典键限字符串或十进制整数；整数转为字符串键。例如 {1: "a"} → {"1": "a"}。
- {1: "a", "1": "b"} 拒绝，因为转换后的键冲突。
- 不支持元组、集合、bytes、raw/f/triple 字符串、推导式、函数调用、赋值、注释、对象或布尔键。
- 支持常用单字符转义、两位十六进制、四位 Unicode 和八位 Unicode 转义；未知转义拒绝。
- 输入中的代理项 Unicode 转义拒绝，请用完整码点或直接粘贴字符。

## JSON 输入范围

严格 JSON，不接受单引号、注释、尾逗号、非字符串键或多余 token；重复键报错。对象键按成员列表保留，不依赖普通 JavaScript 对象，因此 __proto__、constructor 等键可正常转换。

## 错误、限制与隐私

- 最大输入 1 MiB，嵌套上限 128 层；解析错误附行号和列号（UTF-16）。
- 独立 Worker 执行，3 秒超时终止；修改输入、手动停止、离开页面都会终止任务。
- 没有 eval、Function、PHP 或 Python 运行时，不执行用户代码，不访问网络，不写本地存储。
- 复制进入系统剪贴板，下载保存本机；页面清空不清除这些系统内容。
- PHP/Python 下载的是数据字面量片段，不附加 PHP 标签或变量赋值，不应当作完整脚本运行。
