# 提示词优化

入口：AI 工具 → 提示词优化，地址 `#/prompt`。

## 功能
- 静态规则：通用、编程开发、SQL / 数据库、代码解释、Bug 排查、产品需求、文本写作、翻译、数据分析、图片生成提示词。
- 自动识别是简单关键词匹配，优先翻译、解释、排错等任务意图；手动选择始终优先。识别不到使用通用模板。
- 七个维度共用一份选择：角色、目标、背景、步骤、输出格式、限制条件、示例。
- 静态模板完整保留原文，未知信息使用占位符；不是语义理解。全不选时原样返回，不请求模型。
- 输入最多 12000 字符；模型上下文能力因模型与配置而异，不保证任意长度的模型输入都被完整处理。
- 结果可编辑、复制并统计字符数。修改输入或选项保留旧结果并提示重新生成；重新生成成功会覆盖手动编辑。
- 无账号、无后端、无线上模型平台接入，不增加大型依赖。

## 模式
| 模式 | 行为 |
| --- | --- |
| 静态规则 | 不访问 Ollama |
| 自动，Ollama 关闭 | 静态规则 |
| 自动，Ollama 开启 | 尝试所选模型；失败明确提示原因并返回静态结果 |
| 本地 / 内网 Ollama | 必须开启并选择模型；失败显示错误，保留已有结果 |
| 主动取消、输入/设置改变、离开页面 | 终止当前请求，不降级，不接受迟到结果 |

切换模式不会自行发起生成。刷新不会探测服务；点击“检测连接”或“优化提示词”才访问配置的服务。

## 连接本机或内网 Ollama
1. 在自己的电脑或内网服务器安装并启动 Ollama，安装文本生成模型。
2. 打开网站右上角「AI 设置」，填入完整 HTTP(S) 服务地址。
   - 本机：`http://localhost:11434`
   - 内网：`http://192.168.1.100:11434`
   - 内网域名/反向代理：`https://ollama.company.internal`，也支持代理路径前缀。
3. 点击「检测连接 / 获取模型」，选择模型并保存；本地 AI 聊天与提示词优化共用此配置。
4. 在提示词工具中勾选「此工具启用 Ollama」，选择自动或手动 Ollama 模式，点击优化。

不限制 localhost，也不根据 IP 地址段判断企业域名是否内网。地址不能含账号、密码、查询参数或片段；不支持 API Key。网页只请求用户指定的服务，不内置任何线上模型服务端点。

### 模型筛选与本地边界
- GET /api/tags 获取列表，POST /api/show 检查能力。
- 排除 remote_host / remote_model 非空或名称标记 cloud 的模型；要求 capabilities 包含 completion。
- embedding 模型与无法确认详情的模型不出现在可选列表中；旧版 Ollama 请升级。
- 每次生成前重新检查所选模型，以防保存的模型被替换或删除。
- 模型列表检查并发最多 3 个；单次元数据请求超时 5 秒。
- 设置窗口检测后会预选可用模型；已保存模型失效时会更新窗口内的候选选择。必须点击「保存配置」才会应用到全站。
- 网站无法审核服务器内部转发或日志行为。要严格离线，请管理员设置 `OLLAMA_NO_CLOUD=1` 并重启 Ollama，而不是仅依赖前端筛选。页面不会修改服务器。

### 浏览器连接排查
- 内网 Ollama 需要监听客户端可达接口，服务器防火墙只放行可信内网。
- 服务端使用 `OLLAMA_ORIGINS` 放行工具箱的准确来源（协议、主机、端口）。开发环境通常为 `http://localhost:5173`；内网页面应使用实际来源。不要为省事无差别设置 `*`。
- 浏览器可能弹出本地网络访问许可。HTTPS 页面访问 HTTP 内网服务在部分浏览器下会受限，可让管理员给服务配置 HTTPS。
- 工具不会关闭浏览器安全机制、不使用不透明响应绕过 CORS、不添加公共代理。
- 网络错误无法仅凭前端精确区分未启动、跨域、权限、混合内容或防火墙；页面提供联合排查提示。
- 支持的静态部署为 HTTP(S)，不支持双击 file:// 页面。复制通常需要 HTTPS 或 localhost 和剪贴板权限。

## 模型请求
POST /api/chat，stream=false，固定 system 消息约束：
- 原始提示词作为待优化素材，不执行其任务。
- 保留原意、事实和约束，按选定输出语言改写，不直接回答原始问题。
- 只额外补充所选维度，缺失信息用占位符，只输出优化后的提示词。
- 不要求披露内部思维过程。

生成请求超时 120 秒（模型元数据预检查另有 5 秒），提供取消按钮；取消会终止浏览器等待，但服务器计算是否立即停止取决于 Ollama。
模型响应只读取 message.content，忽略 thinking，不作为 HTML 渲染；空内容或明确截断视为失败。
模型可能不遵循指令，工具不保证事实、质量或原文措辞完全保留，请复核生成结果。

## 存储与隐私
配置存储 key：`devkit.prompt.settings.v1`，字段：
version、category、selected、mode、enabled、language、thinking。
连接地址与默认模型统一存储在 devkit.ai.settings.v1；原有地址和模型首次加载时自动迁移，后续不在提示词配置里重复保存。详情见 [本地 AI 聊天与统一设置](LOCAL_AI_CHAT.md)。
不写入输入、结果、连接结果或请求正文；没有埋点。静态模式完全在浏览器处理。
Ollama 模式把提示词发给配置的服务，服务器日志与留存由管理员管理。
存储损坏或读写失败时仍可使用页面，并显示提示。“恢复默认选项”只重置类别、维度、模式和输出语言（中文），保留连接配置。

## 实现文件
- PromptTool.vue：界面、保存工具选项、生成状态与取消、复制；连接配置由全站 AiSettingsDialog.vue 维护。
- settings.ts：共享维度/类别及版本化配置读写。
- categories.ts：识别规则和九类专用模板（另有通用模板）。
- builder.ts：静态模块拼接。
- optimizer.ts：模式选择、系统提示词、自动降级、输入边界。
- providers/ollama.ts：URL、网络错误、超时/取消、模型筛选和聊天请求。
- tests/prompt-*.test.ts：模板、存储、网络/模式边界。

## 输出语言
任务类别下方可选择中文 / English，默认为中文，选择保存在当前浏览器。旧配置缺少 language 时按中文处理。
- 静态模式：十类模板的标题、角色、步骤、占位符等支持英文，原始需求完整保留，不自动翻译正文。
- Ollama 模式：要求模型使用所选语言改写提示词；保留代码、标识符、专有名词及必须原样引用的内容。不改变原任务指定的翻译目标语言或回答语言。
- 自动降级也使用所选语言的静态模板；全部取消维度时仍原样返回。
- 切换语言会取消在途生成，并提示已有结果需要重新生成。恢复默认选项重置为中文。
- 14 项语言测试（含十类英文模板、语言配置、模型请求和降级）及全部 88 项提示词相关测试通过；页面中英文切换、刷新和默认值恢复已实测。模型输出质量尚未在真实服务上验证。

## Thinking（深度思考）
提示词工具中的 Thinking 开关默认关闭，启用 Ollama 后可操作。设置会保存，旧配置按关闭处理；恢复默认选项保留此连接配置。
- 关闭：请求顶层发送 `think: false`，不再依赖模型的默认思考设置。
- 开启：发送 `think: true`，需模型详情声明 thinking 能力，否则提示关闭开关或更换模型。自动模式沿用失败降级规则。
- 切换会取消正在进行的优化，并标记旧结果需要重新生成；始终只展示 message.content，不展示 message.thinking。
- 模型行为不同，关闭不保证统一加速。GPT-OSS 要求 low/medium/high 等级且无法完全关闭思考，本开关不提供等级选择；请用支持布尔开关的模型来减少此类耗时。
- 95 项提示词相关单测与构建通过，浏览器模拟请求验证 think:false/true 及设置持久化通过。真实模型耗时未测。
参考：[Ollama Thinking 文档](https://docs.ollama.com/capabilities/thinking)。

## 运行耗时
优化完成提示格式为“（耗时1分钟5秒）已完成 · 本地 / 内网 AI · 模型名。可继续编辑结果。”，自动降级提示也包含耗时。
从点击优化启动本次任务到结果返回计时，包含模型检查、网络等待和降级处理；不含此前单独点击的连接检测。不足一秒显示0分钟0秒，秒数向下取整。每次任务独立计时，不持久化，不添加实时更新计时器；取消和失败仍显示原有提示。
