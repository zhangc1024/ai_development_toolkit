# Windows 桌面版人工验收单

适用：DevKit 图片工具 0.1.0 内测版。自动测试结果见 WINDOWS_DESKTOP_RELEASE.md。本单的未勾选项不代表已验证。

## 已安装应用

Windows checkout 下 output/windows-install-test/app/DevKitImages.exe。可使用开始菜单中的“DevKit 图片工具”。

## 系统“另存为”（待用户反馈）

1. 打开“图片 ↔ Base64”，加载示例或本地图片，点击下载图片。
2. 在真正的 Windows 对话框中，选择安装目录之外的中文目录，修改文件名后保存。预期：生成的图片可外部打开。
3. 再次下载并按取消。预期：无失败提示、不出现额外文件。
4. 以相同文件名再次保存：分别测试覆盖确认的取消和接受。预期：取消保留原文件，接受后文件正常。

- [ ] 选择目录保存
- [ ] 取消
- [ ] 重名覆盖（取消/接受）

反馈需注明实际检查项目和是否正常；仅将用户明确反馈的项目记为“用户人工验收通过”。

## 显示与电源（需要目标硬件）

- [ ] Windows 系统缩放 125%/150%/200%，保持原生窗口和文字清晰、按钮可操作。
- [ ] 不同 DPI 显示器间移动窗口，检查画布预览、弹窗、焦点、导出尺寸。
- [ ] 处理时休眠/唤醒，确认没有旧结果覆盖；保存期间唤醒后检查结果或明确失败、临时文件清理。

当前机器已检测为单显示器、1920×1080、系统比例 100%；页面缩放的自动测试不能代替这些项目。
