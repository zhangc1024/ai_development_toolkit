# Windows 0.1.5：文件夹批量处理

日期：2026-11-02。

## 0.1.6 界面调整

按选定设计改为顶部「单图 / 文件夹批量」切换和两行输入、输出路径栏。突出目录名，长路径省略并可悬停查看；文件清单默认收起，失败重试、打开输出目录和报告放在展开清单中。三个工具共用布局，后台处理规则不变。

## 使用

图片压缩 / 格式转换、图片加水印、照片水印边框页面提供「文件夹批量」模式。单图操作和原有 ZIP 批处理保留；网页版不显示文件夹入口。

1. 选择输入文件夹；需要递归时先勾选「包含子文件夹」，更改后重新选择。
2. 从清单点击「预览」选择样图，在下方现有界面调整参数。
3. 选择输出文件夹和同名策略，再开始批量处理。
4. 可取消、查看每个文件的状态、打开输出文件夹、导出 JSON 报告，或仅重试失败项。

压缩与边框无需样图也可按当前参数执行；水印必须先设置至少一个可见水印（支持用 NEF 作样图）。开始后锁定当前工具操作；失败重试沿用上一轮设置。若要应用修改后的设置，点击「开始批量处理」重新执行全部可处理文件。切换工具或关闭窗口会取消当前任务，不在后台继续。

## 输出规则

- 原图不修改；不提供覆盖原图功能。
- 输出与输入不能相同；输出在输入内部时，排除已扫描的输出目录文件。文件清单固定，本轮不加入新增文件。
- 保留输入相对目录结构。
- 后缀：压缩 `-compressed`、水印 `-watermarked`、边框 `-frame`。
- 同名默认加 ` (1)`、` (2)` 等序号，也可跳过；不会静默覆盖已有结果。跳过策略在提交结果时判断，仍可能发生解码和处理。
- 结果先分块写入同目录临时文件，完整写入后提交；取消时清理当前临时文件，已成功结果保留。
- 一张图片解码失败继续下一张；输出权限、空间等保存错误停止整批，未执行项目保持待处理。
- 不跟随符号链接 / Windows 目录联接，拒绝向被替换为链接的子目录输出。

## 工具差异

### 压缩 / 格式转换

沿用现有压缩 Worker、档位和单张 60 秒超时。默认开启 Nikon HE/HE★ 内嵌 JPEG 兼容，不代表完整 RAW 解码；逐项展示解码与编码说明。目标格式和原格式回退与单图压缩一致，原格式保留结果也复制到输出文件夹。

### 图片加水印

0.1.8 起支持静态 JPG / PNG / WebP / HEIC / HEIF / NEF，单张上限 100 MiB，维持现有像素限制。水印中心分别按图片宽高比例调整，字号按短边比例缩放；切换批量样图保留水印。保留文字、透明度、角度、颜色及同时压缩设置。不会把未加水印的原图作为压缩回退结果。

### 照片水印边框

沿用模板、样式、字段显示开关和导出设置。默认逐张读取 EXIF 和品牌，空字段隐藏。只有勾选「批量统一覆盖拍摄信息」才使用样图的全部字段；取消「逐张识别品牌 LOGO」后统一使用当前 LOGO（包括不显示、自定义 LOGO）。每张照片重新计算输出布局。

## 范围和实现

- 默认串行，按需读取单张文件，完成后释放位图、画布与 Worker；不把整个文件夹或全部结果装入内存。
- 每次扫描最多 10000 个文件、遍历最多 50000 个目录条目；超限明确要求缩小范围，不静默截断。清单每页 50 项。
- 压缩与边框继续维持 100 MiB 输入限制；各工具不因批量模式自动增加格式或像素支持。
- 不含暂停 / 断点续跑、批量编辑流水线、九宫格 / 二维码 / Base64 接入，以及按组拼接或双重曝光。
- `electron/batch.cjs` 管理主进程目录选择及不透明文件 ID；渲染进程不能提交任意磁盘路径。
- `src/platform/FolderBatch.vue` 负责公共队列与状态，工具提供参数快照和单文件处理函数。
- `electron/files.cjs` 增加可选提交回调；原有单文件保存行为保持不变。
