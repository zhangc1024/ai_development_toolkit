## 二、公共能力

已实现：统一菜单注册、名称搜索、Hash 路由、待开发状态、响应式布局、本地处理提示、JSON/纯文本编辑器和系统能力封装；四种编码工具共用转换工作区。

后续按需：主题、工具收藏、最近访问的工具入口、公共文件导入组件。可以持久化非敏感偏好；不自动保存用户输入和密钥。

## 三、后续增量

所有工具已完成当前文档列出的范围，后续根据反馈扩展；不自动增加后台。

## 四、范围变更规则

新增工具同时补充：输入/输出定义、是否联网、格式和容量限制、错误行为、敏感数据策略、最小验收用例、桌面兼容点。不要仅写“支持某工具”。

若新增账号同步、远程请求代理或真实 PHP 执行环境，再单独设计后台；不能因为已有规划就提前引入服务器依赖。

## 新增：正则、二维码、2FA

已实现正则匹配与超时保护、二维码 PNG 生成下载、TOTP 验证码与配置导入。逐项说明见 [EXTRA_TOOLS.md](EXTRA_TOOLS.md)。
