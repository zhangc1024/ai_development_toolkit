# 0.1.1：2500 万像素照片支持

日期：2026-11-02。按用户要求调整照片像素上限，沿用已批准的未签名内测配置。

- 共享图片输入校验从 1600 万提高到 6400 万像素；任一边仍不得超过 16384。水印、九宫格、图片与 Base64 转换、二维码识别等入口及相关说明同步更新。
- 图片拼接输出从 3200 万提高到 6400 万像素，可容纳两张 5000×5000 图片的水平拼接（10000×5000）。
- 照片边框、图片压缩和双重曝光原有的 6400 万输入能力保持一致。
- 文件字节数限制保持原配置；旧图片工具的单文件 10 MiB 限制仍有效。本轮未调整照片边框自定义 Logo 和合成成品的独立上限。

验证：
- 752 项单元测试通过；覆盖 2500 万、6400 万边界、超限及非法尺寸。
- Web 类型检查、生产构建与静态页面生成通过。
- Windows 0.1.1 桌面生产构建和 NSIS 安装包生成通过。
- scripts/desktop-25mp-test.mjs 对打包应用的 8 个图片工具导入真实 5000×5000 JPEG/PNG；7 项导出文件均重新解码确认尺寸，二维码识别内容符合预期，未出现页面异常。
- Base64、水印和压缩保留 5000×5000；拼接成品 10000×5000；九宫格、双重曝光、照片边框按各自设置导出。
- 验收结果保存于 output/desktop-25mp/。测试使用生成图片，不包含用户拍摄样本。

交付：release/DevKit-Images-0.1.1-win-x64.exe，校验见 release/SHA256SUMS-0.1.1.txt。安装更新后生效；现有 0.1.0 安装不会自动更新。本轮未替用户关闭或覆盖正在使用的旧版应用。
