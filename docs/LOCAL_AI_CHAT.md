# 本地 AI 聊天与统一 AI 设置

## 入口与使用

- 首页 → AI 工具 → 本地 AI 聊天，地址 `#/ai-chat`。
- 点击网站右上角「AI 设置」，填写 Ollama 地址，点击「检测连接 / 获取模型」，选择本地文本模型，保存。
- 聊天与提示词优化共用此地址和默认模型。提示词优化仍保留自己的启用开关、优化方式与 Thinking 选项。
- 聊天必须配置 Ollama，没有静态或在线 AI 降级。没有图片、文件上传或云端模型入口。
- Enter 发送；Shift+Enter 换行；中文输入法选词时 Enter 不会发送。
- 支持纯文字多轮对话、流式回复、停止生成、复制回复、新建、切换、删除及清空会话。
- 回复按原始文本显示（包括代码和 Markdown），不执行模型返回的 HTML。
- 地址支持 localhost、局域网 IP、内网域名及 VPN。localhost 指浏览器所在设备。

## 保存规则

- 全站连接配置：localStorage，键 `devkit.ai.settings.v1`，仅保存版本、地址与默认模型。
- 首次读取会迁移原 `devkit.prompt.settings.v1` 中的地址与模型。已有全站配置优先；提示词工具后续只保存自己的选项，不再写入地址和模型。
- 聊天记录：IndexedDB，数据库 `devkit.ai.chat.v1`，对象仓库 `conversations`。
- 新消息提交和生成结束时保存；生成过程中约每 700ms 保存一次快照。
- 切换会话、离开工具或修改全站连接配置会停止当前生成，保留已收到的回复。
- 意外刷新或浏览器退出可能丢失最后一次尚未写入的片段；重新打开时将未完成回复标记为中断。
- 保存失败会明确提示，可继续临时聊天并重试保存。
- 删除当前会话与清空全部聊天需要确认；清空不删除 AI 配置。
- 数据只属于当前浏览器、当前网站来源；不同协议、域名或端口互不共享。清除网站数据会丢失记录，不含跨设备同步。
- 多标签页会同步全站连接配置；会话列表加载于页面进入时，暂不支持多标签页并行编辑同一会话。

## 上下文与限制

- 单条输入最多 12000 个 UTF-16 字符单位，与输入框 maxlength 一致。
- 每次请求最多携带近期 20 轮完整问答，且历史加本次输入不超过 24000 字符。
- 按完整问答轮次裁剪，不截断单条历史消息；遇到超出字符预算的轮次后停止向前追加。
- 停止、失败、被截断或刷新中断的问答轮次不进入下一轮上下文，原消息仍保存在历史里。
- 省略消息时显示本次省略数量；字符预算不是模型 token 窗口保证，实际模型仍可能截断上下文。
- 回复正文上限 100000 字符；连续 120 秒没有收到流数据会超时。
- 输入框上方提供 Thinking（深度思考）开关，默认关闭；每次请求显式发送对应的 think 值。开启前检查模型 thinking 能力，不支持时明确报错且不发送聊天正文。思考内容不展示；某些模型不能完全关闭思考。
- Thinking 选择单独保存在 localStorage 的 devkit.chat.settings.v1 中，与提示词工具的开关独立；读取失败默认关闭并提示。生成中修改开关会停止当前回复，已收到内容保留。
- 发送前重新校验模型详情，拒绝云端模型和无法确认文本生成能力的模型。
- 会话不绑定旧服务：改变全站配置后，后续发送将使用新服务和默认模型，并携带符合上述规则的当前会话历史。

## 连接排查

连接配置需要 Ollama 提供 `/api/tags`、`/api/show` 和 `/api/chat`。设置页仅获取服务及模型信息，不发送聊天内容。

服务端需允许网页来源（`OLLAMA_ORIGINS`）；局域网部署还需配置监听地址与端口。浏览器可能要求本地网络权限，HTTPS 页面访问 HTTP 内网地址也可能被限制。设置窗口会显示当前网页来源。

如需确保服务离线推理，可在 Ollama 服务端设置 `OLLAMA_NO_CLOUD=1`。网页只能检查服务返回的模型信息，无法保证服务器内部代理、日志或网络策略。

接口及部署说明参考：[Ollama Chat API](https://docs.ollama.com/api/chat)、[Ollama FAQ](https://docs.ollama.com/faq)。

## 实现位置

- `src/ai/settings.ts`：共享响应式配置、localStorage、旧配置迁移及跨标签页同步。
- `src/components/AiSettingsDialog.vue`：唯一设置窗口，测试连接与默认模型选择。
- `src/tools/chat/ChatTool.vue`：聊天页面、会话管理、生成与保存生命周期。
- `src/tools/chat/core.ts`：完整问答筛选与上下文预算。
- `src/tools/chat/ollama.ts`：NDJSON 流解析、UTF-8 分块、取消、超时和输出限制。
- `src/tools/chat/storage.ts`：IndexedDB 事务及中断状态恢复。
- `src/tools/registry.ts`：入口，首页和导航自动沿用工具注册表。
