# 0.1.3：默认启用批量 Nikon HE/HE★ 兼容

日期：2026-11-02。用户反馈 0.1.2 仍报 HE★ 无法解码：该版兼容开关默认关闭，仍需手动勾选。

0.1.3 将 ZIP 批量“尼康 HE/HE★ 兼容：使用相机内嵌 JPEG”默认设为开启：
- 普通 RAW 继续完整解码；HE/HE★ 自动进入已验证的内嵌 JPEG 分支，结果明确标注来源和尺寸。
- 不将内嵌 JPEG 说成 RAW 原始像素解码；没有有效预览的损坏/不支持 RAW 仍失败并保留原件。
- 用户仍可主动关闭兼容选项，严格要求完整 RAW 解码。
- 原格式模式转换结果不变小则保留原文件；要输出 JPG，请选择目标 JPG。HEIC 修复保持有效。
- 免安装交付：DevKit-Images-0.1.3-win-x64-portable.zip。关闭旧应用，解压到新目录，直接运行其中的 DevKitImages.exe；原桌面快捷方式不会自动更新。

验证使用 D:\\test 的两张 HE★ NEF 和 HEIC，脚本 scripts/desktop-batch-fix-test.mjs：
- 首轮不操作兼容复选框，断言默认勾选，默认原格式批量处理不出现失败；HEIC 逐字节保留。
- 第二轮选择 JPG、均衡压缩，两张 NEF 导出为有效的 5568×3712 JPEG。
- 桌面构建包含类型检查；ZIP 完整性及 app.asar 与实测应用一致性另外核对。
