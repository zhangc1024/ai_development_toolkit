# JSON 工具功能说明（已实现）

## 1. 输入与数据生命周期

输入为标准 JSON 文本，根值允许对象、数组、字符串、数字、布尔值和 null。空白输入提示“请先输入 JSON 内容”。

- 直接粘贴或编辑；提供行号、JSON 语法高亮和撤销/重做。
- 输入始终保留，转换结果展示在右侧只读编辑器。
- 每次编辑输入，会终止旧任务并清除旧结果、旧校验状态。
- 每次操作先清除旧输出；操作失败时不会留下上一次成功结果。
- 页面刷新、关闭或离开当前工具会丢失内容。
- 不写入 localStorage、IndexedDB、URL、日志或远程服务器。
- 字符统计按 JavaScript UTF-16 code unit 计数，例如 emoji 通常计为 2；行数按 CRLF/CR/LF 统计；容量按 UTF-8 字节数。

## 2. 格式化

**入口：**“格式化”按钮；编辑器内 Ctrl+Enter / macOS ⌘+Enter。

**选项：**2 空格（默认）、4 空格、Tab。修改缩进选项后需再次点击格式化，不自动改写现有结果。

**行为：**先严格校验，通过后重新布局字符串外空白，使用 LF 换行。保留输入中的属性顺序、重复键、数字和字符串 token 原文。

例如 `9223372036854775807`、`1.2300`、`1e+300`、`-0`、`"\\u4e2d"` 不会被 Number 转换或重新序列化。格式化输出前后无多余空白。

**不包含：**键排序、值修改、Unicode 自动还原、业务字段修复。

## 3. 压缩

**入口：**“压缩”按钮。

先校验，再拼接原始 token，移除字符串外空格、Tab 和换行。字符串内部空格和转义完全保留，结果为单行 JSON（字符串中的换行仍为转义）。

显示输出字符数、UTF-8 容量；输出比输入小时显示容量减少百分比。这里是文本压缩，不是 gzip/zip 压缩。

## 4. 校验

**入口：**“校验”按钮。

通过时显示“符合标准 JSON 语法”和根值类型；不生成格式化结果，右侧显示下一步提示。校验前会清除旧结果。

拒绝：

- 单引号字符串、无双引号键名。
- 注释、尾逗号、缺失冒号或逗号。
- undefined、NaN、Infinity 等非 JSON 值。
- 非法转义、未转义控制字符、字符串未闭合。
- 多个顶层值、数字前导零等非法数字格式。

重复键不视为语法错误，保持原文，不做去重；业务应避免依赖重复键。语法通过不表示符合 JSON Schema，也不表示数值能被 JavaScript Number 精确表示。

## 5. 错误定位

显示首个解析错误的中文原因、从 1 开始的行列号。“定位错误”将输入光标移动至解析器报告的位置，并滚动到该处。

缺失字符可能报告在其后的 token 或文档末尾，这是解析器发现错误的位置，不一定是最初产生错误的位置。列号按 UTF-16 计数。

超大输入、超时、Worker 启动失败属于资源或运行问题，不伪造语法位置。

## 6. 编辑器辅助能力

| 功能 | 行为 |
| --- | --- |
| 语法高亮 | 输入与输出都按 JSON 着色，不渲染输入中的 HTML |
| 行号 | 方便定位与阅读 |
| 搜索 | 点击搜索图标或编辑器内 Ctrl/⌘+F；使用 CodeMirror 搜索面板 |
| 结构折叠 | 行号旁可折叠；结果底部“折叠/展开”操作全部可折叠结构 |
| 自动换行 | 两侧统一切换，仅改变显示，不修改文本 |
| 只读结果 | 可选择、搜索、复制，不允许直接改写 |
| 快捷键 | Ctrl/⌘+Enter 格式化；编辑器提供标准撤销、重做和搜索 |
| 清空 | 同时清空输入、结果、状态并终止正在运行的任务 |

编辑器使用 CodeMirror 默认搜索面板，部分面板文字可能为英文。没有实现 JSON 树形数据浏览器。

## 7. 示例、导入、复制与下载

### 加载示例

替换输入为内置嵌套示例并立即格式化。包含中文、数组、布尔值、null 和超出 JS 安全整数范围的订单 ID，便于验证无损处理。

### 导入

选择本机 .json 或 .txt 文件。只读取本地字节，不上传。

- 文件上限 1 MiB，超限文件不读入。
- 按 UTF-8 严格解码，无效 UTF-8 提示失败；UTF-8 BOM 由解码器去除。
- 导入完成后由用户选择格式化、压缩或校验。
- 导入期间用户编辑或选择另一文件时，旧异步读入结果不会覆盖最新内容。
- 文件选择器的扩展名过滤仅用于方便选择，不替代内容校验。
- 原始文本直接粘贴包含 BOM 时，按严格 JSON 校验报告；可通过 UTF-8 文件导入处理。

### 复制

只允许复制非空结果。调用系统剪贴板；浏览器拒绝授权或环境不支持时，提示在编辑器选中后 Ctrl+C，不假报成功。

### 下载

只允许下载非空结果，生成 UTF-8、MIME 为 application/json 的 `result.json`，使用本地 Blob 临时 URL。提示“已请求下载”不代表浏览器已完成保存。

## 8. 性能与限制

- 输入上限：1,048,576 UTF-8 字节（1 MiB）。
- 嵌套上限：128 层。
- 格式化/压缩/校验均在 Web Worker 内执行。
- 处理超过 5 秒终止线程并提示；修改输入或离开页面也终止线程。
- 输入超限仍可编辑和删除，但不能执行转换。
- 文本编辑、渲染和消息复制仍占主线程资源，不能承诺任意设备上大文件零卡顿。
- 格式化可能增加输出体积，当前不面向日志文件级别的超大 JSON。

## 9. 最小验收清单

1. 空输入操作有提示；顶层 null、true、数字、字符串均通过。
2. 嵌套对象与数组支持三种缩进，输入不被覆盖。
3. 大整数、小数尾零、指数、转义在格式化后再压缩保持原文。
4. 单引号、尾逗号、注释校验失败，定位按钮移动光标。
5. 搜索、折叠、换行、快捷键有效。
6. 导入、复制、下载、清空有效；刷新后无历史内容。
7. 修改输入立即清空旧结果；只校验不会保留旧转换结果。
8. 超大输入与超深嵌套被拒绝，移动端没有横向页面溢出。
