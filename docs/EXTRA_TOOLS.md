# 正则、二维码与 2FA 工具

这三个工具是纯 Vue 页面，路由分别为 `#/regex`、`#/qrcode`、`#/totp`。所有计算在本地，不调用业务后台，不自动保存输入。依赖随 dist 打包，适合静态 CDN 部署。

## 正则表达式测试
- 输入表达式本体（不写两侧斜杠）、标志及测试文本。
- 使用 JavaScript RegExp；支持标志 dgimsuvy，重复、不兼容或运行环境不支持的标志会报错。不是 PHP PCRE。
- g 遍历全部匹配；未设置 g 只执行一次；y 遵循从索引 0 开始的粘连匹配规则。
- JSON 结果列出 index、end、text、groups、named。位置单位为 UTF-16 code unit，结束位置不包含。未参与匹配的捕获组显示 null；命名组未参与字段按 JSON 序列化省略。
- 零宽匹配会自动推进；Unicode 模式按码点推进，避免死循环。最多展示前 1000 项，超出明确提示截断。
- 表达式限制 10,000 字符，文本限制 200,000 字符（UTF-16）。独立 Worker 执行；2 秒超时终止，包括初始化耗时。提供停止操作。
- 修改输入、清空、离开页面会终止任务并清除结果。示例、结果复制可用。
- 本期不提供替换、PCRE 引擎、图形语法解释或原文高亮。

## 二维码生成
- 输入普通文本或链接，支持中文、emoji、空格及换行，不修剪原始内容，不访问链接。
- 使用 qrcode 库生成黑白 PNG；四模块静区；纠错 L、M、Q、H，像素倍率 4、8、12，默认 M / 8。
- 输出按模块整数倍率绘制；页面可缩小展示，下载保留原始尺寸。提供预览、下载 qrcode.png、示例、清空。
- UTF-8 上限 2953 字节；实际容量受编码模式、纠错等级影响，不能容纳时提示缩短。空内容拒绝。
- 修改内容或选项立即清除旧预览，异步生成使用版本保护避免旧结果覆盖。
- 不提供扫码识别、Logo、自定义颜色或批量生成。建议使用实际目标设备检查扫描结果。

## 2FA：TOTP 动态验证码
- 输入 Base32 密钥；忽略空白和大小写，校验字符、长度、填充和尾部未使用位。最多 4096 输入字符。
- SHA1 / SHA256 / SHA512，6 / 8 位，周期为整数 1–300 秒。默认 SHA1 / 6 位 / 30 秒，T0 为 Unix epoch。
- 每 250ms 从设备时间重新取样，到周期边界更新验证码及剩余秒数；后台页面可能被节流，恢复后按设备时间重算。不联网校时。
- 支持导入 otpauth://totp 配置的 secret / algorithm / digits / period 参数；不保存标签、issuer 或账号。重复核心参数拒绝，不支持 HOTP。
- 导入成功清空 URI 输入并启动。修改参数会停止旧验证码；开始时校验；停止并隐藏保留输入，清空会删除密钥和配置。
- 密钥和配置默认密码输入，可主动显示；离开工具或刷新不保留。不写 localStorage、URL、日志或下载文件；JavaScript 字符串无法保证物理内存擦除。
- 可复制当前验证码；复制内容会进入系统剪贴板，本工具不自动清理系统剪贴板。
- 示例使用公开测试密钥，不能用于真实账号。这里不验证服务端是否接受验证码，也不创建或绑定账号。
- 不提供账号管理、密钥随机生成、绑定二维码生成、相机扫码、HOTP 或云同步。

## 开发与桌面端
- 页面：src/tools/extra/ExtraTool.vue；纯逻辑：core.ts；正则 Worker：regex.worker.ts。
- 正则耗时执行隔离在 Worker；TOTP 输入受限，小规模 HMAC 本地同步执行；二维码使用本地库。
- 窗口卸载清除计时器和 Worker；不跨窗口共享密钥。桌面壳仍需允许 Worker、Canvas、Blob/静态资源，并接入剪贴板和下载能力。
- 未制作 Windows 安装包；当前实现可继续复用到 Electron/Tauri 前端。

## 依据
- [RFC 6238（含勘误）](https://www.rfc-editor.org/rfc/inline-errata/rfc6238.html)：TOTP 与标准向量。
- [node-qrcode](https://github.com/soldair/node-qrcode)：二维码生成与纠错选项。

## 2FA 二维码图片导入

2FA 页面支持选择、拖放或粘贴二维码图片，成功后自动填入配置并启动验证码。

- 支持 otpauth://totp 配置，读取密钥、算法、位数和周期；非法或重复参数拒绝。
- 支持纯 Base32 密钥二维码，默认 SHA1 / 6 位 / 30 秒，明确提示核对服务端设置，不沿用旧参数。
- 不支持 HOTP、迁移二维码、普通网址或相机。请使用仅含一个二维码的清晰图片。
- PNG/JPEG/GIF/WebP，最多 10 MiB、1600 万像素、单边 16384；静态首帧白底绘制，最长边缩至 2048，Worker 超时 5 秒。
- 开始识别停止旧验证码；失败保留旧密钥但不重新启动。成功替换参数，并恢复密钥隐藏状态。
- 编辑、重新选择、停止、清空或离开会丢弃旧任务。已开始的浏览器解码可能继续，但结束后关闭位图且不写回旧结果。
- 不上传、不预览或保存图片，不记录识别原文；仅当前页面内存保留导入后的密钥。不证明服务端绑定成功。
