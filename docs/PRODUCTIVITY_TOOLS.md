# UUID、随机字符串、文本工具与 HTTP 状态码

## 公共约定

| 工具 | 路由 | 输入 | 输出 |
| --- | --- | --- | --- |
| UUID 生成 | #/uuid | 数量、大小写、连字符 | 每行一个 UUID |
| 随机字符串 | #/random | 长度、数量、字符集 | 每行一条字符串 |
| 文本 Diff | #/diff | 原文本、新文本、粒度、首尾空白选项 | 新增/删除/相同片段与统计 |
| 文本处理 | #/text | 多行文本和处理选项 | 处理后文本、处理前后行数 |
| HTTP 状态码 | #/http-status | 关键词、分类 | 名称、中文含义、排查方向 |

全部在浏览器本地运行，不上传输入，不写历史记录。离开工具或刷新即丢弃页面内容。复制会进入系统剪贴板，下载会保存到本机；页面清空不会删除已下载文件或系统剪贴板。

修改参数或输入立即清除旧结果。UUID、随机字符串和文本结果支持复制及 TXT 下载；Diff 支持差异 JSON 复制下载。生成器清空结果时保留设置，文本工具清空双侧输入及结果。

## 1. UUID v4

- 使用 crypto.getRandomValues 生成 16 字节，再设置版本 4 和 RFC 变体位。
- 默认小写、带连字符的 8-4-4-4-12 格式；可大写或移除连字符。紧凑形式是显示选项。
- 数量为 1–1000 的整数，默认 10，一行一个，无尾部额外换行。
- 例：xxxxxxxx-xxxx-4xxx-[89ab]xxx-xxxxxxxxxxxx。
- 若无安全随机源，明确报错，不回退 Math.random。
- 随机不等于绝对唯一，工具不跨批次记录或查重。
- 本期不支持 v1/v3/v5/v7、时间排序、命名空间或服务器 ID 服务。

## 2. 随机字符串

- 默认长度 24、数量 10、大小写字母与数字。
- 快捷字符集：字母与数字、纯数字、十六进制、排除易混淆字符；也可直接编辑。
- 长度按 Unicode 码点计（emoji 通常一个码点，但组合 emoji 可能多个）；不按视觉字形计。
- 字符集自动去重，避免重复字符加权。支持 2–256 个不同码点；不允许空白、控制字符和孤立 UTF-16 代理项。字符集原始输入最多 2048 UTF-16 字符。
- 长度 1–4096、数量 1–1000；长度 × 数量不得超过 100,000。
- 使用安全随机字节和拒绝采样：仅接受小于 256 - (256 % 字符集长度) 的字节，再取模，避免简单取模导致的概率偏差。
- 每个位置独立等概率选择；不保证包含每个字符类别，也不承诺生成记录互不重复。工具不保存密码。
- 生成上限用于限制 UI 阻塞；底层随机字节分块读取，不超过 Web Crypto 单次调用限制。

## 3. 文本 Diff

### 操作
- 左侧原文本，右侧新文本；可交换左右。
- 默认按行比较；可改为按 Unicode 码点比较。
- 可选“忽略每行首尾空白”。该选项先 trim 每行再比较，结果展示规范化文本。
- 统一 CRLF、CR 为 LF；行内空白、行序和末尾换行仍参与比较。
- 新增绿色 +、删除红色 −、相同灰色 =；同时标识文字符号，不只依赖颜色。换行用 ↵ 作为显示提示，实际 JSON 保留换行字符。
- 统计新增/删除行数或码点数。两侧相同和两侧空文本都有明确反馈。
- 所有内容以文本渲染，输入 HTML 不会执行。
- JSON 片段包括 value、added、removed、count；这是可检查的差异数据，不是 Git patch。对规范化输入，可分别拼接非 added / 非 removed 片段还原原侧 / 新侧。

### 限制
- 按行每侧最多 200,000 UTF-16 字符；按字符每侧最多 20,000。
- 最多 5000 个差异片段；库算法超时 1500ms，Worker 外层 3 秒终止保护，均包含相应执行开销。
- 手动停止、修改输入和页面卸载均终止 Worker。
- 本期不提供文件夹/仓库比较、自动合并、补丁应用或文件导入；可粘贴文本使用。

## 4. 文本去重 / 排序 / 去空行

默认去空行与去重启用，首尾 trim 和忽略大小写关闭，排序为保持顺序。

处理顺序固定为：
1. 可选 trim 每行首尾空白。
2. 可选删除空行（包括只有空白的行）。
3. 可选去重，保留第一次出现的文本。
4. 可选升序或降序排序。

- 关闭 trim 时，空格仍参与去重与排序。
- 忽略大小写使用 JavaScript toLowerCase，仅作用于比较键，不修改保留文本。
- 排序按 UTF-16 字符串序，不是数字大小、自然排序或拼音排序。例如升序 1、10、2。
- 比较键相同的行保持原先后顺序。
- CRLF、CR 统一成 LF。非空输入末尾换行视为额外空行；空输入为 0 行。
- 上限 200,000 UTF-16 字符；Worker 隔离，3 秒超时保护。
- 显示处理前后行数和移除行数；空输出仍可复制下载。支持结果作为下一次输入。
- 本期不提供字段分列、大小写全文转换或复杂脚本。

## 5. HTTP 状态码查询

- 内置 IANA 登记的单个代码条目；关键词匹配数字、英文名、中文含义和提示，英文不区分大小写。
- 1xx/2xx/3xx/4xx/5xx 分类筛选与搜索同时生效。查询限 200 字符。
- 支持每条复制、结果数、无匹配提示。
- 中文含义和排查方向是辅助说明，不代表诊断结果；结合响应头、正文及日志判断。
- 401 与 403、307/308 与 301/302 等常见区别分别说明。
- 104 明确标记临时登记和 2026-11-13 到期日；305 弃用，306/418 未使用，510 废弃；418 同时保留茶壶历史关键词。
- 不枚举未分配区间，不收录厂商私有码，不主动请求用户网站。
- 数据核对日期：2026-09-16。后续更新时复查 [IANA 状态码登记表](https://www.iana.org/assignments/http-status-codes/)；查询过程不联网，只有主动打开来源链接才联网。

## 6. 模块与后续桌面复用

- src/tools/productivity/core.ts：UUID、随机字符串、行处理纯函数。
- diff.ts：Diff 规范化及算法；text.worker.ts：文本处理任务与差异任务。
- http.ts：静态登记表和筛选。
- ProductivityTool.vue：共用页面、输入失效、Worker 生命周期、复制下载。
- 安全随机源、Worker、剪贴板、下载能力需在未来桌面壳中验证；无后台依赖。
- 不含 Windows 打包、自动更新和原生文件权限改造。

## 7. 最小验收

- UUID 版本位为 4、变体为 8/9/a/b，批量数量正确，格式设置立即失效旧结果。
- 随机字符全部属于去重后的字符集；使用注入字节验证拒绝采样分支，不能靠少量统计声称均匀性。
- Diff 能还原两侧规范化输入；换行、Unicode、空文本、首尾空白选项测试通过。
- 文本处理验证管道顺序、保留首项、稳定排序及末尾空行。
- HTTP 搜索 401、限流、分类冲突与不存在的代码有正确结果。
- 浏览器验证报告见 [VERIFICATION.md](VERIFICATION.md)。
