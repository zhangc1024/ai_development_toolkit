# JSON 结构化对比

## 入口与操作
菜单“JSON 结构化对比”，路由 #/json-diff。
1. 左右粘贴严格 JSON。
2. 点击“比较 JSON”，或在编辑器按 Ctrl / ⌘ + Enter。
3. 在原文查看红色背景与下划线；点击差异列表或上一处/下一处同步定位两侧。
4. 可交换左右、加载示例、清空、复制或下载差异 JSON。

JSON 编辑器将粘贴的 CRLF / CR 换行统一为 LF，避免显示 CR 控制字符；比较坐标基于编辑器中的文本。比较、导航或标记不会改写字段和值。修改任一侧会立即清除两侧全部标记和结果，需要重新比较。不自动格式化，也不自动保存输入。

## 比较语义
- 对象按解码后的字段名匹配，忽略字段顺序；递归比较嵌套字段。
- 数组按下标比较，不忽略顺序，不按 id 匹配；额外元素标为缺少。
- 字段不存在与 null 不同；数字 1 与字符串 "1" 不同。
- 字符串按解码后的值比较，例如 "a" 与 "\u0061" 相同。
- 数字不使用解析树的 JavaScript Number 值；直接规范化数字原文的十进制有效数字和指数。1、1.0、1e0 相同，-0 与 0 相同；9007199254740992 与 9007199254740993 不同。
- 不展开指数为巨大字符串，因此大指数不直接造成大数内存分配；非零数字指数长度限制为 1000 位。
- 路径使用 $["user"]["name"]、$["items"][0]，字段含点号、括号、引号时仍能消除歧义。
- 容器类型发生变化时只报告该容器一项，不再次报告所有子节点。

## 原文标记
| 差异 | 左侧 | 右侧 |
| --- | --- | --- |
| 值变化 | 值标红 | 值标红 |
| 类型变化 | 值/容器标红 | 值/容器标红 |
| 右侧缺少字段 | 整个属性（键和值）标红 | 编辑器上方提示缺少路径 |
| 左侧缺少字段 | 编辑器上方提示缺少路径 | 整个属性标红 |

缺少侧没有可标记的原文，导航定位到其父容器起点，不插入占位字段。存在侧选中对应范围；当前差异有额外红框。导航自动展开折叠区域，差异列表默认只包含不同项。

高亮使用 CodeMirror Decoration；内容变化时 StateField 立即清空装饰，避免失效坐标残留。不插入 HTML 到用户内容，也不依赖全局字符串替换匹配重复值。

## 校验与限制
- 两侧均使用既有严格 JSON 校验；语法错误附左右侧、行列提示。
- 拒绝重复键，包括通过转义写出相同名称的键，避免覆盖或匹配歧义。
- 每侧最多 1 MiB、128 层；最多 2000 项差异。超限报错，不展示静默截断的部分比较。
- Worker 最长 5 秒；支持停止，修改内容与页面卸载也终止旧任务。
- 列表每侧预览最多 160 个 UTF-16 字符，过长显示省略号；编辑器仍有全文。
- 结果 range 使用原始输入的 UTF-16 偏移，记录 from/to，结束不包含。下载包括 path、kind、两侧范围、父容器定位范围和截断预览；不包含完整原文，不是可应用补丁。
- 相同文本显示“结构与值相同”；空字符串不是合法 JSON，null、[]、{} 等合法顶层数据均可比较。

## 本地与桌面复用
不请求后台，不上传输入，不使用持久存储。复制和下载由用户主动触发。未来桌面壳可复用纯比较核心、Worker 和现有平台封装。

文件：
- src/tools/json-diff/core.ts：精确数字比较、结构递归与原文范围。
- json-diff.worker.ts：隔离执行。
- JsonDiffTool.vue：双侧编辑器、列表、导航与生命周期。
- src/components/CodeEditor.vue：可选 marks 与 reveal 定位能力；其他编辑器默认行为保持原样。
