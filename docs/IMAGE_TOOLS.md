# 图片 ↔ Base64 与二维码识别

## 范围和入口
- 图片 ↔ Base64：#/image-base64。
- 二维码识别：#/qr-reader；与原有 #/qrcode 生成工具并存。
- 纯前端，依赖随构建打包，不上传图片、不请求远程图片，不保存历史。
- 文件选择、拖放或页面粘贴图片均自动处理；多文件仅取第一个。粘贴监听当前页面 paste 事件，不主动读取系统剪贴板。
- 切换工具、清空和取消会终止识别 Worker、丢弃旧结果并释放 Blob URL。异步文件读取和图片解码使用版本检查，旧任务不能覆盖新任务；浏览器已经开始的解码可能仍继续，完成后关闭 ImageBitmap。
- 不接入摄像头、远程 URL、扫码登录或账号系统。

## 图片 → Base64
1. 选择“图片 → Base64”，导入本地图片。
2. 检查预览、文件名、类型、尺寸和字节数。
3. 选择 Data URL（默认）或纯 Base64。
4. 复制结果或下载 image-base64.txt；也可以下载原图。

支持 PNG、JPEG、GIF、WebP，按文件头判别类型，再由浏览器解码确认图片有效，不能只修改扩展名冒充图片。

编码保留原文件字节，不经 Canvas 重编码，元数据和动画数据也会保留。因此输出不是“去元数据”或“压缩图片”；Base64 通常比二进制更大。显示的编码长度不包含 Data URL 前缀。

## Base64 → 图片
1. 选择“Base64 → 图片”，粘贴 Data URL 或纯 Base64。
2. 点击“还原图片”，查看预览和类型信息。
3. 下载 image.png / image.jpg / image.gif / image.webp，保存解码后的原始字节。

规则：
- 只接受标准 Base64 字母表；填充可省略，但错误填充、尾部非零填充位拒绝。
- 忽略空格、Tab、CR 和 LF。
- Data URL 只接受 image/png、image/jpeg、image/jpg、image/gif、image/webp 和 ;base64, 形式；image/jpg 归一为 image/jpeg。
- 声明 MIME 必须与文件头一致；纯 Base64 自动识别 MIME。
- 不接受 Base64URL、HTML 包装、CSS url(...) 包装、HTTP 图片链接、SVG 或其他文件。
- 必须实际解码成功，只有 PNG 文件头但内容损坏仍报错。
- 编辑输入立即清除旧预览，失败不会保留上一张图。
- 本模式粘贴剪贴板图片会切回“图片 → Base64”并转换。

## 二维码识别
- 读取本地图片，在 Canvas 白底上绘制静态首帧，再把像素传入 jsQR Worker。
- 每张图片返回一个 QR 码；包括文本内容、QR 版本和原始字节 Hex。
- 同时尝试正常和反色识别。输入透明区域按白底合成。
- 最长边超过 2048 时等比例缩小识别，以限制 CPU 和内存；预览、原图不改写。密集二维码可能因缩小而识别失败，建议先裁剪。
- 无二维码、遮挡、模糊、错误图像和超时有提示。
- 内容只作为文本渲染；URL 不自动打开，HTML 不执行，otpauth 不自动导入 2FA。
- 可主动复制或下载 qrcode-content.txt。非 UTF-8 / 特殊编码数据可能无法正确显示为文字，可检查原始字节。
- 暂不支持条形码、批量或多二维码识别、相机、动画逐帧扫描。

## 容量与运行限制
- 图片文件 / 解码后字节：非空，最多 10 MiB。
- Base64 文本：最多 15 MiB 字符。
- 图片尺寸：最多 1600 万像素，任意边最多 16384。
- 文件字节限制在读取前检查；像素限制在 createImageBitmap 完成后、Canvas 分配前检查，因此不能保证压缩图片在解码阶段完全不消耗大内存。
- 二维码 Worker 超时 5 秒，可取消。超时不包含文件读取和浏览器图片解码。
- 图片转换使用浏览器解码和本地编码；大文件可能短暂占用主线程，暂无流式大文件处理。
- 复制和下载是用户主动行为，会分别写入系统剪贴板和本机文件；清空页面不撤销这些操作。

## 模块
- src/tools/images/core.ts：文件头、类型与大小校验，标准 Base64 编解码。
- ImageTool.vue：文件、拖放、粘贴、预览与任务失效管理。
- qr.worker.ts：jsQR 解码与错误返回。
- 复用 security/bytes.ts 的二进制 Base64 方法，不使用原文本 Base64 的 UTF-8 文本解码路径。
- 没有服务器依赖；未来桌面壳需支持 createImageBitmap、Canvas、Worker、Blob URL、文件选择和复制下载。
