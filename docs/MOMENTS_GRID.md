# 一图切九格

入口：图片工具 → 一图切九格，地址 `#/moments-grid`。

## 使用

1. 选择或拖入一张静态 JPG、PNG 或 WebP。文件最多 10 MiB、1600 万像素、单边 16384 像素；不支持 GIF、APNG、动态 WebP、HEIC、SVG。
2. 默认居中裁成正方形。拖动调整位置，双指缩放；也可用缩放滑块、聚焦裁剪区后的方向键。缩放范围 1～6 倍，自动限制位置，避免露白。
3. 点击生成，串行输出九张 1080×1080 图片，按文件实际内容识别并保留 JPG / PNG / WebP 格式。PNG、WebP 保留透明区域；棋盘格仅用于预览，不写入结果。JPG、WebP 重编码质量为 0.9，保留格式不代表保留原始字节或元数据。浏览器不支持原格式编码时，按实际输出使用 PNG，并显示提示。
4. 点击结果查看大图并长按保存，或逐张下载。需要 ZIP 时先打包，再点击下载。按从左到右、从上到下的 01～09 顺序发布。

输出文件名为 `moment-grid-01.<原格式后缀>` ～ `moment-grid-09.<原格式后缀>`，例如 PNG 为 `moment-grid-01.png`；发生编码回退时后缀跟随实际格式，ZIP 为 `moment-grid.zip`。序号和分隔线只在预览层显示，不写入图片。预览仅模拟九格构图，不承诺微信具体间距和压缩效果。

浏览器不能静默保存九张到系统相册；下载可能进入文件管理器，ZIP 需要解压。微信内置浏览器下载受限时可长按保存或用系统浏览器打开。文件名不能保证相册显示顺序，发布前应自行核对。

原图裁剪区域小于 3240×3240 会提示放大；固定输出尺寸不代表增加原图细节。第一版只有单图切九格，没有多图、模板、文字、旋转、AI、历史存储或后端。

## 实现与资源

- `src/tools/moments-grid/core.ts`：归一化中心点、缩放、边界约束、手势锚点和九格源区域；预览与导出共用几何计算。
- `images.ts`：复用已有图片容器与尺寸校验，在解码前拒绝超限图片；使用浏览器方向校正解码，不再次手工应用 EXIF。createImageBitmap 不可用或失败时回退 HTMLImageElement。
- 导入读取原图，生成最长边 1200px 工作 Canvas，释放原始解码资源。Vue 使用 shallowRef 管理资源，不深度代理像素或保存 Base64。
- 编辑只使用工作图，requestAnimationFrame 合并预览更新。导出重新解码一次原图，一个 Canvas 串行渲染高清结果和 240px 缩略图，不创建整张 3240px 大图。
- 结果列表仅解码缩略图；打开详情才显示单张高清图。ZIP 库按需加载，复用现有 zip.js，已编码图片使用 ZIP 存储模式避免无效二次压缩。
- 更改裁剪会撤销旧结果；换图、清空和卸载释放 Canvas、Bitmap 和 ObjectURL。
- 处理中锁定编辑、替换与重复提交，允许取消。浏览器已开始的解码或 toBlob 不能即时中断，完成后丢弃结果，不启动重叠作业。
- 不上传图片、不请求第三方素材、不持久化图片和裁剪状态。刷新或离开后需重新选择照片。
